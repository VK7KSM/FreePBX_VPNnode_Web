## 第二轮补审修复

- 明确识别同源管理接口返回的 Cloudflare 原生 HTML 429 / Error 1027，转换为一致的额度错误。只对本地合成的等待时间采用距离 UTC 午夜与十五分钟的较小值，防止边缘恢复延迟导致额外冻结一整日；服务器原有有效 `Retry-After` 不截断。普通限流和登录失效保持原语义。
- 主动拉取、普通任务、系统配置结果在网页隐藏或明确退出登录后暂停查询。重新登录并回到前台后继续原任务，暂停不消耗查询预算，也不重新下发命令；后台媒体运行不受影响。
- CF 用量正常每十五分钟读取，已知每日额度错误保持低频复核而不逐渐延后至数小时。离开网页后清理计时器；已补虚拟时钟行为测试，未为测试消耗生产请求。
- 故障操作点击时冻结事件，处理中禁止切换，避免等待接口期间误操作另一事件。只有确切不存在的状态文件才能初始化；损坏内容保留。状态写入和读取使用相同体积上限，避免写出之后无法恢复。
- 故障元数据和文件下载、SIP 状态均遵守长秒数及 HTTP 日期格式的等待时间，不提前重复请求。
- D31 开发任务已反馈候选客户端补充过期风险的真实布尔值，未知保持空值。其通讯录分页仍待冻结生产任务名称，网络写入仍待恢复守护及独立确认验收，本补丁不提前开放这些操作。
