# elfRemote 开发进度

## 2026-09-07 当前范围

本文件为可公开的脱敏进度索引；工作区 `remote.md` 保存逐项开发记录，私有捕获目录保存真机证据。源码上传、生产部署、真机验收分别记录，不互相代替。

当前只在 D22-XX 开发测试。通用功能在 XX 完成后，再统一更新 D22-JJ 与 D22-BB。JJ 用于插卡、开启 GPS 的蜂窝测试；BB 用于无卡、关闭 GPS 的室内 Wi-Fi 测试。其他机型随后适配。

## 已实现及已有证据

- 管理网页复用既有账号，服务端校验会话；管理员登录后直接操作，设备无人值守。
- 未配对设备注册、状态报告、列表与地图管理；配对决定离线后的列表保留，配对码不在网页泄露。
- 每次上报的位置和公网 IP 历史持久保存，支持时间查询、分页和历史地图查看。
- MQTT 推送、领取回执与完整报告分段显示；Wi-Fi 每 15 分钟报告，主动报告成功后重置周期。
- XX 已验证启动先连接 MQTT、短暂断网恢复、默认网络回调提前重连、息屏报告。本机日志在断网及重启期间保留。
- root 任务目录改为应用组可访问，XX 已验证实际应用身份可写、普通非 root 身份不可写。
- 更新器已增加真实 APK 包名、版本、证书校验、下载限额与状态原子写入；XX 已验证只读制品检查，尚未完成产品自更新验收。
- 完整日志拉取已在 `1acfc64` 发布生产；私有 R2 保存日志，管理员下载验证会话，设备回执持久化。服务器 71 项测试、Android 101 项测试通过；真实日志链路验收正在进行。
