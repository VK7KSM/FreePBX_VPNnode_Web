# KV 鉴权读取复用与登录退避修正

日期：2026-09-12。记录人：D22_Web_Dev。

## 已完成的修改

- `panel-kv.js` 将同一 KV 绑定的在途读取合并；普通配置保存最多 128 个键、15 秒的本地快照。返回对象独立复制，调用方修改对象不能污染其他请求。
- 认证资料、注销记录、迁移会话不保存跨请求的成功快照，避免在 KV 原有缓存之外叠加新的注销或改密生效延迟。同一个 HTTP 请求内使用同一份读取结果；认证期限与版本仍逐次验证。
- KV 写入和删除前后均清除本实例缓存及请求复用世代；写入之前已经开始、随后才返回的旧读取不能重新填入缓存。失败请求只短暂合并 2 秒，始终返回服务不可用，不使用旧认证资料放行。
- 配置保存前绕过本地快照重新读取 KV，避免把本实例缓存里的旧字段覆盖到最新可见配置；仍沿用整组保存合同。已有请求内的配置读取失败后允许重新查询。
- 匿名或明显格式错误的管理 Cookie 直接返回未登录，不为无效凭据访问 KV。退出、改密和迁移统一使用带失效处理的写入函数。
- 浏览器同页面重复会话检查合并为一个请求；重复的同一就绪回调仅执行一次。服务故障采用 1、2、4 分钟递增退避，上限 15 分钟；如果服务端要求等待更久，以服务端为准。支持秒数和 HTTP 日期两种 `Retry-After`。401 不继续自动检查。

## 接线与剩余边界

Worker 和 DO 的重复鉴权由主任务统一调整，本记录的模块修改没有通过请求头跳过认证。DO 的 ADB 和媒体分支位于通用认证之前，不能误认为这些分支已有第二次身份检查；未经补齐检查不得移除它们的外层认证。任务创建后的推送副作用必须保留。

KV 是最终一致存储，本地失效不能广播到其他运行实例，本修改不承诺全球即时注销，也没有增加认证成功结果的跨请求缓存时间。普通配置新增的本地快照最多保留 15 秒；配置写入只绕过本地缓存，不能把 KV 本身描述为强一致事务。多人或多实例同时改写同一配置组的原有竞争限制仍然存在。

上述计数是本地合同测试，不是生产全天消耗结论。真实用量仍需由主任务部署后的短时单页面验收和 Cloudflare 统计确认；不能把关闭遗留测试会话后的下降全部归功于代码缓存。

## 补审修正：原生额度错误与 SIP 长退避

同日追加。Cloudflare 在 Worker 执行之前返回的 HTML 错误页面不能依靠 Worker 自己改写，因此在共用浏览器 `fetch` 包装器中精确识别：只处理同源 `/api/` 接口的 HTTP 429、`text/html` 响应，并要求正文同时含 Cloudflare 与完整的 `Error 1027` 标记。识别后仍保留 429，转换为可读 JSON，代码为 `workers_quota_exceeded`，提示为“CF Workers 日请求额度已用尽，等待恢复”。`Retry-After` 指向下一个 UTC 午夜；本地时区不参与日额度计算。

普通登录限频的 JSON 429、其他 Cloudflare 错误、非 API 页面、外站响应与 401 保持原有语义。归一化不会把有效登录变成未登录，也不会把无法识别的响应当作额度错误。原生页面读取或识别失败时保留原响应。

SIP 的读取退避此前把服务端等待时间裁为 900 秒，且不识别 HTTP 日期，现改为遵守完整的秒数或日期等待时间，只限制在浏览器定时器可表示范围内。正常业务轮询间隔未调整。同步生成 `sip-client-source.js`，未改动设备页面源码。


26 项通过。其中新增 4 项验证原生 1027 归一化、误判防护、401 语义保留和 SIP 两小时退避；全部为本地响应替身，不访问生产服务。

## 跨日边界补审

同日再次追加，取代上一节“合成等待直接到午夜”的实现描述。官方[每日请求限制](https://developers.cloudflare.com/workers/platform/limits/#daily-requests)明确免费额度在 UTC 午夜重置，但没有承诺各边缘节点在午夜零延迟恢复。若午夜刚过仍收到旧的 1027，直接计算下一个午夜会错误等待近 24 小时；中途升级套餐后也可能出现类似误等待。

现在仅对浏览器自行合成的 1027 等待时间采用“距下一 UTC 午夜和 15 分钟的较小值”。这是低频复核上限，避免跨日或服务提前恢复后长期冻结，不调整正常业务频率。原服务器已经提供的有效 `Retry-After` 原样保留，包括两小时等长等待；普通 429 不被改写。JSON 的 `retry_at` 对应实际下次复核时间，`reset_at` 仅保留按 UTC 计算的预计日额度重置时刻，不新增界面文字。

新增假时钟覆盖午夜前两分钟、午夜后一秒和午夜后十二分钟；前者等待至午夜，后两者最多 15 分钟。普通 429 的真实 7200 秒及原生 1027 已带的真实 7200 秒均不截断。相关鉴权、退避及 SIP 测试合计 28 项通过。
