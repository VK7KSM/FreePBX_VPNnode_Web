# D31 第十二批网页接口交付

记录日期：2026-09-12。责任工作线：D22_Web_Dev。

## 实施范围

本批接通 D31 LOCAL 通讯录只读分页，以及 Wi-Fi 布尔开关的网络事务确认。复用现有设备身份、任务、进度和历史接口，不新增常驻轮询，不改变 D22 原通讯录写入及普通系统配置语义。本批没有操作真机，没有新增网络开关控件。

## 通讯录

- 新任务 `contacts_page`，能力为严格布尔 `managed_contacts_page_v1`；支持 `open/page/close`，每页最多32条。
- 使用原厂 LOCAL 快照及真实 `next_offset`，固定120秒保留，翻页不续期，不写入旧 `device.contacts`。
- 页面按设备隔离状态，建立后只自动读取第一页，后续由用户翻页。未知提交保留原任务编号查询，不自动重新采集。
- 过期、关闭、凭据变更和错误快照在下发前拒绝，返回409及明确的 `not_enqueued=true`；保存失败等未知错误仍不能当成未入队。
- 内容通过现有任务服务器保存；不宣称只存在设备或浏览器内存。错误保留此前页面并显示实际失败，不伪装成空通讯录。

## 网络事务

- 沿用 `system_config`，参数为 `group=wifi/action=set/key=enabled`，附带冻结的 `network_transaction`；独立确认沿用 `task-progress` 的 `action=network-confirmation`。
- 创建时绑定设备凭据摘要；确认严格校验原任务、本地任务摘要、APK、目标、原启动、单调期限和随机号。确认响应先保存，再返回；允许确认不等于执行成功。
- 每任务最多保存64个随机号及回执；同随机号改写拒绝，后续轮询不撤销旧合法允许。原窗口不因重试延长。
- 真实提交、回滚、未知状态及清理分别判断。未开始拒绝须提供 `NOT_STARTED` 无变更和已清理证据；普通退出码或空结果不构成成功。
- 未确认的在途网络事务保留忙槽；重注册后归档但没有实际完整终态的网络记录，不按普通30天期限自动清除。终态不可被不同回执改写。

## 验收与发布边界

- 最终本地 `npm test` 为414项通过，零失败；`npm run embed:check`、`npm run build:assets`、`git diff --check` 均通过。
- 独立静态审核和网络专项14项测试通过，覆盖随机号重用、旧允许补传、未决历史及未开始拒绝。真实 Worker 处理函数测试使用本地合成数据，不是生产真机验收。
- `network_write` 保持关闭。私有 `D31_NETWORK_ACCEPTANCE_JSON` 可限定一条设备记录、一个候选 APK 摘要及最多24小时的截止时间；默认未配置即不允许。本批未设置真实验收值，不把该值写入源码。
- D31_dev 负责客户端合同对齐、候选构建、实际通讯录分页，以及断网恢复、取消、超时、重启和清理的真机联合验收。通过前不得开放日常网络写入能力。
- 两份完整协议随本记录保存于同目录的“D31第十二批通讯录分页合同”和“D31第十二批网络确认冻结合同”文档。
- 回滚以本批之前的已发布提交为基线，使用可审核的反向提交重新部署；不能靠删除未决任务或设备数据回滚业务状态。
