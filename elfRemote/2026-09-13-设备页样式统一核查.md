# 设备页样式统一核查

日期：2026-09-13。范围：公共网页排版与样式，不修改客户端、设备配置、账号字段、媒体协议或丢失模式执行逻辑。

## 发现的问题

真实渲染函数与当前样式生成的浏览器页面中，“设备”“通信终端”“功能设置”标题分别为15.2、14、16.8像素。丢失模式按钮为12.8像素、输入框为13.33像素，其余功能页通常为12像素；型号下拉框也有默认字号残留。普通操作按钮实际高度分布于28至36像素，输入框分布于30至38像素，缺少统一层级。

## 统一后的视觉基准

| 元素 | 规范 |
| --- | --- |
| 三个大标题 | 15像素、字重600、20像素行高、颜色`#d4deec` |
| 列表及标题栏设备名称 | 12像素、18像素行高 |
| 功能页正文、子标题、普通操作按钮 | 12像素；正文行高1.8；子标题字重400 |
| 信息卡标签与内容 | 标签11像素、内容12像素；灰蓝标签与浅色正文分层 |
| 八个功能导航按钮 | 36像素高、18像素图标、统一圆角与间距 |
| 功能页普通操作按钮 | 30像素高、6像素圆角、18像素行高 |
| 普通输入框与下拉框 | 34像素高、12像素字、统一边框与内边距 |
| 系统分类导航 | 保留左侧竖排及分隔线，34像素行高控件 |
| 终端专用区域 | 保留340像素终端高度、等宽命令字体及30像素命令行控件 |
| 语义颜色 | 操作为现有绿色，停止及危险操作沿用暗红；选中为蓝色，禁用仍为灰色 |

共用规则放在`worker.js`的`devicesUiStyle`常量中，仅由设备页引用，避免影响代理及SIP管理。已有照片时间、图表坐标、权限等紧凑辅助信息保留其用途所需的尺寸与等宽字体。颜色仍配合文字与禁用状态，不仅用颜色区分操作含义。

## 核验

使用实际生产渲染函数与合成设备资料，浏览器逐页检查远程终端、更新客户端、系统配置、通信录、设备轨迹、文件管理、丢失模式、添加型号，并检查系统配置六个分类。三个标题的计算样式完全相同；普通按钮和输入框字号均为12像素；桌面1320像素宽下无页面横向溢出。八页截图已逐一查看，终端高度与左右布局保留。

同时核验媒体标题栏：连接为绿色、断开复用解除配对的暗红色，设备名称与历史记录水平对齐。媒体状态位于连接按钮后，长短状态切换不移动照片、功能按钮和流量区。

本次是界面验收，没有派发设备命令，没有触发删除、清除、连接媒体或账号保存等业务操作。合成页面和截图位于本地忽略目录`output/playwright/device-ui-audit-20260913/`；这些截图不能作为设备业务验收证据。


## 2026-09-13 紧凑操作按钮尺寸更正

依据用户截图反馈，将添加设备、通信终端连接与断开、功能设置的编辑与停用及解除配对、终端维护操作及连接ADB纳入同一操作按钮规格：高度30像素，左右内边距10像素，字号12像素，字重500，行高18像素，圆角6像素。连接、断开、编辑、停用实测均为44×30像素；四字按钮为68×30像素。原业务颜色保留，绿色连接与暗红色断开继续使用白字。此条更正此前32像素标题栏按钮规格。

浏览器以实际渲染函数和合成资料逐项测量上述按钮，包括连接与断开两个状态，并检查八个功能页；桌面宽度无横向溢出。现有449项测试全部通过，嵌入源码校验与静态资源构建通过。截图与尺寸结果保存在本地忽略目录，不涉及设备命令或媒体连接。
