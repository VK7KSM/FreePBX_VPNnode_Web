# 2026-09-11 CF服务分工与无功能损失优化复核

## 约束与已完成事项

不能降低设备报告、实时控制或媒体功能来省额度。现有账号继续使用，不部署第二账号，不自动升级付费。Workers请求、DO请求/存储、KV读写、R2操作与媒体流量分别计量；免费额度属于不同资源，不能相互抵扣。

已上线：重复设备/型号请求合并、一次DO内鉴权和读取、故障有界退避、后台无用查询暂停；登录及代理/SIP低频配置迁KV；页面、脚本、样式、图片迁Static Assets。账号密码保持原值，真实新签名登录及退出已验证。XX156已验证客户端退避，但JJ152存在故障恢复后积压每分钟补传与新增报告耦合，另行止血及修复，不能称整体用量问题已全部解决。

## 当前官方能力核对与采用顺序

| 服务 | 当前适用场景 | 决策及限制 |
| --- | --- | --- |
| Static Assets | 静态页面、脚本、样式、图标 | 已上线。直接静态响应免费不限次，不运行业务Worker；API与订阅仍动态处理。 |
| Workers KV | 当前登录资料、代理/SIP低频配置、IP查询缓存 | 已上线。每次仍验证会话；不搬高频设备状态。跨节点最终一致，同类别并发修改还需防覆盖。 |
| Durable Objects | 设备身份、任务领取、回执、强一致计数 | 保留。不是将全部数据装进同一DO；高频读写减少重复往返，真实业务不能裁掉。 |
| DO WebSocket Hibernation | 浏览器接收设备变化通知 | 下一项适合的优化。状态变化通知替代空闲重复查询，连接断开可退回查询；保留任务进度、设备超时/离线和重新同步。现有媒体/ADB普通WebSocket内存会话须独立评估，不能直接切休眠丢会话。 |
| R2及S3短期签名地址 | APK、文件、照片、录音录像 | 保留私有存储。后续可使正文直接传R2，Worker只鉴权、签发和确认，减少分块转发请求。仍须校验目标/摘要/大小，完成后清暂存、媒体七天清理；不能仅有上传链接而丢掉确认与清理流程。需要独立最小权限S3凭据与CORS验证，不与后移的电脑点对点直传混淆。 |
| Realtime SFU/TURN | PTT、电话、麦克风和视频的实时链路 | 使用已有链路，媒体数据不通过HTTP逐帧轮询。官方SFU和独立TURN各有媒体计费及免费流量说明，不能套用Workers请求额度；RealtimeKit无同样免费档，不为UI便利替换。 |
| Cloudflare Tunnel | 暴露甲骨文已有HTTP/WebSocket服务 | 现有节点已使用。适合源站连接和将来独立备用入口；Tunnel本身不是备用应用/数据库，不会自动接替耗尽的Worker，也不把设备全部接隧道作为必要条件。 |
| Workers Cache | 公共、可复用的动态生成响应 | 2026年现行文档新增可在执行Worker前命中缓存，与Worker内Cache API不同。当前公开内容已静态托管，没有必要为收益很小而全局启用。管理、登录、设备、实时状态及秘密订阅不能公开缓存。 |
| Cache API/CDN缓存 | 公共资源及重复上游读取 | Cache API本身在Worker内调用，命中仍执行Worker；普通CDN和Workers Cache分开判断。不能只加缓存响应头就宣称所有业务HTTP免计量。 |
| D1 | 按日期/设备查询大量轨迹、流量历史 | 将来历史规模增长时适合索引查询和聚合；免费档当前日写十万行、总5GB，也有独立读限。数据库迁移本身不减少浏览器对Worker的HTTP次数，本轮不迁。 |
| Queues | 独立异步处理、可重试作业 | 当前已有设备任务队列，不重复建一套。现行免费档每日10000操作、固定24小时保留；通常每消息写/读/删合计3次操作，重试额外计量，不适合替代长期离线设备任务或历史。 |
| Spectrum | 通用TCP/UDP代理 | 自定义TCP/UDP需Enterprise及付费附加项，不是当前免费MQTT/SIP替代方案，不开通。 |

## 下一步验收要求

1. 先修复已证实的异常：积压补传与新采样解耦，正常报告优先，保留历史采样时间；不能清空历史来冒充省流量。GPS与无线定位的修复在XX验收，不在学校蜂窝JJ上开发调试。
2. 对浏览器变更通知采用有限、可验证方案：初始完整同步；变更合并；断线重连同步；任务进度及时；基于时间的离线状态及时更新；登录失效关闭；页面后台处理不妨碍媒体/终端。空闲无变化不重复读DO，不以提高等待时间作为完成标志。
3. R2正文直达另做兼容与回退设计。下载确认前不能删，签名过期可续签，不改变发送文件在蜂窝下也立即下载的既有要求。
4. 统计区分稳定窗口与开发操作；旧页面未刷新仍会继续旧轮询。不能用一次短尾日志或自适应估计承诺全天一定低于限额。
5. Workers本身额度耗尽时，Static Assets仍可显示页面，KV不能运行登录代码。若未来要求此时API也可用，须开发既有服务器上的独立执行入口与数据一致性方案；单纯换存储不够。本轮不擅自部署额外架构。
